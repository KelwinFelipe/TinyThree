Methodology: 300-frame warm-up (JIT stabilization) + 3600-frame collection window (≈60 s at 60 FPS). Metrics: P50 / P95 / P99 frame time · FPS average · GC pause count · TTFF with and without browser cache. Baseline B (Three.js tree-shaken via Vite) used for bundle-size comparisons — not the full 600 KB bundle. Open DevTools Console to see raw results. Results are written to window.benchmarkResults.
